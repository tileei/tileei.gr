# ΤΙ ΛΕΕΙ; ΠΕΤΑΜΕ! — tileei.gr

«Τα μίλια σου γίνονται ταξίδια.»

Ελληνικό εργαλείο για τα μίλια AEGEAN Miles+Bonus: πόσα μίλια κερδίζεις από αγορές, κάρτες Alpha Bonus και καύσιμα, μετατροπή πόντων σε μίλια, αξία εξαργύρωσης, στόχος ταξιδιού και τρέχουσες προσφορές.

- Στατικό site (HTML/CSS/JS), φιλοξενία στο GitHub Pages με domain `tileei.gr`.
- Οι κανόνες και οι πηγές τους βρίσκονται στο `js/data.js`. Οι υπολογισμοί είναι στο `js/calc.js`.
- Οι υπολογισμοί είναι ενδεικτικοί. Ισχύουν πάντα οι επίσημοι όροι κάθε προγράμματος. Το site είναι ανεξάρτητο και δεν συνδέεται με την AEGEAN, την Alpha Bank ή τους συνεργάτες τους.
